# NNDL Playground

这是一个用于记录神经网络与深度学习基础实践的个人学习仓库。项目按照当前进度分类存放，每个项目目录中包含源代码、运行说明和实验结果。

## 仓库结构

- [`completed/`](./completed/)：已经完成的项目
- [`in-progress/`](./in-progress/)：正在进行的项目
- [`planning/`](./planning/)：计划开展的项目

## 已完成项目

- [NumPy-Softmax-FashionMNIST](./completed/Numpy-Softmax-FashionMNIST/)：使用纯 NumPy 从零实现 Softmax 回归，并在 Fashion-MNIST 数据集上进行训练和测试。

## 使用说明

各项目相互独立，所需环境、依赖和运行方式请参阅对应项目目录中的 `README.md`。
