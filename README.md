# NNDL Playground

这是我的神经网络与深度学习学习仓库，用于记录从数学原理、代码实现到实验验证的完整实践过程。

仓库中的项目按照进度分类管理。每个项目均尽量保留分阶段练习代码、完整实现、运行说明和实验结果，方便复习与持续改进。

## 目录导航

- [已完成项目](./completed/)：已经完成并整理好说明文档的项目
- [进行中的项目](./in-progress/)：目前正在开发或学习的项目
- [计划项目](./planning/)：准备在后续开展的项目

| 项目 | 内容 | 状态 |

## 学习目标

- 理解常见神经网络模型背后的数学原理
- 记录实验过程、训练结果与阶段性收获
- 逐步建立结构清晰、可以复现的项目作品集
